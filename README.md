# Historias de Usuario - Proyecto veterinaria

# 1. Registrar cliente
**Como** recepcionista,
**quiero** registrar los datos de un nuevo cliente,  
**para que** pueda acceder a los servicios.

# 2. Registrar veterinario
**Como** administrador,  
**quiero** registrar un veterinario con sus datos personales y especialidad,  
**para que** puedan asignarse sus labores correspondientes.

# 3. Listar clientes
**Como** recepcionista,  
**quiero** ver una lista de todos los clientes,  
**para que** pueda consultar su información cuando sea necesario.

# 4. Buscar cliente por nombre
**Como** recepcionista,  
**quiero** buscar un cliente por su nombre,  
**para que** pueda ver su información más rápido.

# 5. Contar número de clientes registrados
**Como** administrador,  
**quiero** saber cuántos clientes hay registrados en el sistema,  
**para que** pueda generar estadísticas.
